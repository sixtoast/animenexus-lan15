# Awwwards showcase cinematic sequence (Creative Sprint 33)

## Principle

Every step is a **real** product interaction. This is not a showreel of mockups.

Demo / showcase data must stay labelled and must **not** silently write into the user’s shelf or memory (`INTERACTION_CONTRACT`).

## Sequence (live product)

| Step | Creative stack | Real surface |
|------|----------------|--------------|
| 1 | Rive / mascot signal | Lantern-ko on any page (opt-in audio) |
| 2 | View Transition → card | Navigate home/browse → `/anime/[id]` |
| 3 | R3F Living Shelf | Watchlist → **Shelf** mode |
| 4 | Shelf SFX | Select / pair with Sound Settings on |
| 5 | Resonance | Compare two titles on the shelf (`C` then second select) |
| 6 | Memory | Detail page `MemoryVisit` + Memory Room surfaces |
| 7 | Authored motif | `NexusLottie` / loading symbols where wired |
| 8 | Session Cover | `/tools/session-cover` |
| 9 | Normal product | Continue browsing — no “exit demo” theatre |

## Guided page

`/showcase` — ordered checklist linking to the same routes. `robots: noindex`.

## Do not

- Auto-play a fake 3D montage that isn’t the real Shelf
- Inject sample watchlist without clear labelling
- Claim Mux theatre (gate = NO)
- Overwhelm with simultaneous video previews
