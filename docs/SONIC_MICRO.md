# Sonic micro-interactions (Creative Sprint 24)

## Rules

| Interaction | Sound |
|-------------|--------|
| Ordinary click | `ui_tap` — extremely quiet |
| Hover / scroll / typing | **Silent** |
| Route change | `nav_tick` — subtle |
| Major seal / complete | `seal` / `complete` — richer |
| Success / error | Follows **real** outcome only |

## Wired surfaces

| Surface | Cues |
|---------|------|
| Button | `ui_tap` |
| Navbar | `nav_tick`, `menu_open` / `menu_close` |
| Modal | `modal_open` / `modal_close` |
| Seal Moment | `seal` / `complete` |
| Watchlist | seal, progress, remove, complete |
| Radar | `radar_ping`, `signal_acquired`, `error` |
| Oracle | `oracle_tune`, `signal_acquired`, `error` |
| Challenge | `challenge_ok` / `challenge_bad` |
| Sauce | `signal_acquired` / `error` |
| Living Shelf | `shelf_settle`, `resonance` (pair) |
| Memory visit | `memory_focus` |
| Toast | `success` / `error` / `complete` (milestone) |
| Browse / Account | filter + outcome cues |

## Opt-in

All cues respect Sound Settings (default **off** until unlock).
