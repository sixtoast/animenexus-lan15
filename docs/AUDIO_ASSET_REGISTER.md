# Audio asset register (Creative Sprint 22)

## Policy

- **No runtime** Freesound / Openverse / CDN sample packs.
- Production cues are **original PCM WAV** generated by `scripts/generate-ui-sfx.mjs` (AnimeNexus-owned synthesis).
- Third-party discovery (Freesound, Openverse) may be used only for **reference** during design; any future real recording must be licence-cleared and listed here before merge.
- Ambiguous / unknown-licence files are **forbidden**.

## Workflow

```
search (optional reference)
  → inspect licence
  → download source (if any)
  → document here
  → edit/master locally
  → export production asset under public/audio/
  → serve from AnimeNexus only
```

Regenerate current set:

```bash
node scripts/generate-ui-sfx.mjs
```

## Format

- PCM WAV, mono, **22050 Hz**, 16-bit LE (generator default).
- Engine: `lib/sound-engine.ts` + `lib/sound-manifest.ts`.
- User opt-in via Sound Settings (default off).

## Mascot audio

Procedural Web Audio in `lib/mascot/audio.ts` — **not** file-backed; separate mute. Not listed as file assets.

## Adding a new cue

1. Add id to `SoundCueId` + `SOUND_CUES` in `lib/sound-manifest.ts`.
2. Add generation params in `scripts/generate-ui-sfx.mjs` **or** licence-cleared source file + row in this table.
3. Run generator; commit `public/audio/ui/<id>.wav`.
4. Update this register.
