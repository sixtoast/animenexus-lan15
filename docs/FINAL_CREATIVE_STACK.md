# Final creative stack (Creative Sprint 55)

## Mature system (no unjustified overlap)

| Layer | Role |
|-------|------|
| **CSS** | Everyday interaction (press, hover, density, restraint) |
| **NexusIcon** (self-hosted) | Coherent iconography — not live Iconify CDN |
| **Rive** | Stateful 2D instruments (Radar / Oracle / marks) |
| **dotLottie** | Authored vector moments when a sequence is worth it |
| **View Transitions** | Object continuity between routes |
| **React Three Fiber** | Spatial interaction (Living Shelf, Lantern 3D) |
| **Cloudinary** | Site-owned media intelligence & delivery |
| **Local mastered SFX** | Tactile feedback (opt-in, material identity) |
| **Mux** | **Not used** — evaluation gate NO |
| **Spline** | Lab / prototype only — not production embeds |

## Capability tiers

`FULL` → `BALANCED` → `MINIMAL` via `lib/creative-runtime.ts`. Reduced motion forces MINIMAL creative extras. Product functions stay available.

## Soft-fail contract

Missing Rive, blocked audio, lost WebGL, offline Cloudinary → core browse / seal / tools still work.

## Definition of done

The programme succeeds when users do **not** think:

> “That site uses Rive / Lottie / Three.js.”

They should think:

> “Everything reacts.”  
> “Everything feels connected.”  
> “This feels unusually considered.”  
> “AnimeNexus has its own visual language.”

**Technology disappears behind the experience.**
