# Empty-state illustrations (Creative Sprint 9)

## Rules

1. Illustrations only appear when the UI is **actually empty** (no results, empty shelf, etc.).
2. Never use empty art as decoration on filled lists.
3. Title, body, and actions remain the accessible core.

## Component

`EmptyIllustration` via `SignalEmpty` (`kind`: `generic` | `shelf` | `search` | `signals`).

## Fallback

Missing `.riv` → glyph + dashed ring CSS.

## Asset

`public/rive/empty-state.riv` (optional).
