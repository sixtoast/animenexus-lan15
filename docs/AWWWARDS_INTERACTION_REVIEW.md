## Evaluation (silent first, then with sound)

For each clip ask:

1. **Would someone understand what happened?**
2. **Does it feel unique?** (AnimeNexus, not generic SaaS)
3. **Does it feel fast?**
4. **Does it feel on-brand?** (late-night desk / lantern)
5. **Is any animation slowing the user down?**

**Remove or soften anything that fails.**

## Pass criteria

- Micro success ≠ ceremony
- Tools have distinct identity without fighting each other
- Reduced motion still readable
- Soft-fail creative never blocks the task
