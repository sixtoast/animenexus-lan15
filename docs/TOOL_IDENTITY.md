# Tool identity (Creative Sprint 48)

One design language · **different creative personalities**.

| Tool | Primary creative | Audio material | Notes |
|------|------------------|----------------|-------|
| **Radar** | Rive instrument + scan UI | Signal (`radar_ping`, `signal_acquired`) | Ping on sweep / acquire |
| **Oracle** | Rive tuner + cloud bands | Signal (`oracle_tune`) | Radio-like, restrained |
| **Sauce** | Image pipeline + dropzone | Object / success-fail | Cloudinary preview |
| **Living Shelf** | R3F + 2D fallback | Object / spatial | No continuous fanfare |
| **Journey** | Editorial motion | Tonal / memory | Typography-led |
| **Challenge** | State animation | Success / warning | Correct vs wrong cues |
| **Taste** | Data + type motion | Minimal | Almost no decoration |
| **Stats** | Editorial composition | Silent default | Charts > ornaments |

## Rules

1. Do not copy Radar’s ping language onto Stats.
2. Soft-fail creative extras; core tool always works.
3. Use `data-tool-identity` for CSS hooks.
