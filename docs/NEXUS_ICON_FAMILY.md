# AnimeNexus icon family (Creative Sprint 21)

## Proprietary marks

| Name | Concept |
|------|---------|
| `seal` | Lantern Seal (watchlist commit) |
| `signal` | Soft broadcast / alert |
| `resonance` | Taste / mood dimensions |
| `frequency` | Channel / menu density |
| `living-shelf` | Living Shelf surface |
| `taste-mirror` | Taste reflection |
| `night-desk` | Oracle / Night Desk |
| `lantern` | Product mark |

## Geometry rules

- viewBox `0 0 24 24`
- stroke ~`1.75` (secondary rings `1.4–1.5`)
- round caps / joins
- optical center on 12,12

## What we do **not** invent

Close, search, back, chevron — keep universal shapes in the generic set.

## Usage

```tsx
<NexusIcon name="seal" />
<NexusIcon name="resonance" size="lg" />
```

Source: `lib/icons/custom.tsx` → merged in `lib/icons/svg.tsx`.
