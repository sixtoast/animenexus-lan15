# Rive assets (Sprint 4+)

Place authored `.riv` files here. Until a file exists, buttons use CSS-only fallbacks (no runtime error).

| File | Used by |
|------|--------|
| `oracle-ask.riv` | Oracle Broadcast |
| `radar-scan.riv` | Radar Scan horizon |
| `sauce-trace.riv` | Sauce Trace URL |
| `tonight-start.riv` | Tonight (optional CTA) |
| `challenge-submit.riv` | Challenge submit |
| `shelf-mode.riv` | Watchlist Manage ↔ Spatial |

State machine name default: `State Machine 1`  
Boolean inputs: `idle` `hover` `pressed` `loading` `success` `error` `disabled` `attention` `complete`
